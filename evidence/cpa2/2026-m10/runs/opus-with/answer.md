# 【문제 1】 답안 (2026년 귀속 · 2026-06-27 현재 법령)

> **조문 확인 방식 및 한계**: 아래 결론은 law-mcp로 시행일 2026-04-21(소득세법)·2026-05-22(동 시행령)·2026-06-02(조특법)·2026-01-02(부가가치세법) 본문을 직접 조회해 작성했다. 다만 이 도구는 **조문의 "목(가·나·다…)" 단위 본문을 반환하지 않는다.** 목 단위 수치에 의존하는 부분(제129조①1호·6호의 세율, 제62조 각 호의 계산구조, 제14조③8호의 분리과세기타소득, 제12조3호의 식대 한도, 시행령 제87조2호의 서화·골동품 필요경비율, 시행령 제208조⑤2호의 업종별 기준금액)은 **조·항·호까지만 확인**했음을 해당 위치에 표시했다.

# (물음 1) 갑의 금융소득

## <요구사항 1> 이자소득

### 항목별 판단

| 자료 | 판단 | 근거 |
|---|---|---|
| 1. 원본전입 정기예금이자 4,000,000 | **이자소득 ○** (수입시기 = 원본전입일 2026.12.31 → 2026년 귀속) | 소득세법 제16조①3호 |
| 2. 경매입찰 보증금 이자 3,000,000 | **이자소득 ○, 14% 원천징수 → 무조건 분리과세** | 제129조②1호(민사집행법 제113조·제142조 보증금·경락대금 이자 14%) + 제14조③3호(제129조② 세율 적용분은 종합소득과세표준에 합산하지 아니함) |
| 3. 온라인투자연계금융 이자 5,000,000 | **이자소득 ○**(비영업대금의 이익), 등록 온라인투자연계금융업자를 통한 것이므로 **14%** | 제16조①11호·시행령 제26조③ / 제129조①1호 |
| 4. 상업어음할인료 1,000,000 | **이자소득 ×** | 제16조①은 "**채권 또는 증권**의 이자와 할인액"만 열거하고 어음할인액은 열거하지 않음. 갑은 금융업(어음할인업)을 영위하지 않으므로 사업소득(제19조①11호)에도 해당하지 않음 |
| 5. 원금분리 국채의 **원금**에 해당하는 채권의 할인액 2,000,000 | **이자소득 ○** (통합발행 아니므로 제외규정 적용 없음) | 시행령 제22조의2① (원금·이자 분리 시 **원금에 해당하는 채권의 할인액도** 법 제16조①1호의 할인액으로 봄), 동조 ②의 통합발행 제외 미적용 |

### 계산

**이자소득 원천징수세액**
```
① 정기예금이자        4,000,000 × 14% =   560,000
② 경매보증금 이자      3,000,000 × 14% =   420,000
③ 온라인투자연계 이자  5,000,000 × 14% =   700,000
④ 상업어음할인료               ─      =         0
⑤ 국채 원금분리 할인액 2,000,000 × 14% =   280,000
                                        ──────────
                                         1,960,000
```
> **이자소득 원천징수세액 = 1,960,000원**

**종합소득에 포함될 이자소득 총수입금액**
```
4,000,000 + 5,000,000 + 2,000,000 = 11,000,000
 (경매보증금 이자 3,000,000 → 무조건 분리과세로 제외)
```
> **이자소득 총수입금액 = 11,000,000원**
> (금융소득 합계 11,000,000 + 27,000,000 = 38,000,000원 > 2,000만원이므로 전액 종합과세 — 제14조③6호)

## <요구사항 2> 배당소득

### 항목별 판단

| 자료 | 배당소득 총수입금액 | Gross-up | 근거 |
|---|---:|:---:|---|
| 6. ㈜A 주식배당 9,000,000 | 9,000,000 | **○** | 제17조①3호·②2호(잉여금의 자본전입 의제배당). 제3항 단서 제외사유(자기주식소각익·재평가차액 자본전입 등) 없음 |
| 7. 법인과세 신탁재산 분배금 6,000,000 | 6,000,000 | **×** | 제17조①**2호의2**. 제17조③ 본문은 gross-up 대상을 "제1항 **제1호·제2호·제3호·제4호**"로 한정 → **제2호의2는 열거되어 있지 않음** |
| 8. ㈜B 해산 잔여재산분배 | 20,000,000 − 12,000,000 = **8,000,000** | **○** | 제17조②3호(해산 의제배당). 제17조③1호가 배제하는 것은 "제2항**제1호**(감자)" 의제배당뿐이므로 해산 의제배당은 gross-up 대상 |
| 9. 동업기업 수동적동업자 배분소득 4,000,000 | 4,000,000 | **×** | 조특법 제100조의18④ 단서(수동적동업자 배분 소득금액은 소득세법 제17조①의 소득으로 봄). 동업기업 단계에서 법인세가 과세되지 않아 제17조③의 gross-up 대상 배당(법인세 과세된 잉여금 재원)이 아님. 과세연도 종료일 2026.12.31 배분 → 2026년 귀속 |
| 10. 실지명의 미확인 배당 2,000,000 | ─ | ─ | 제129조②2호(45%) → 제14조③3호에 따라 **무조건 분리과세**, 종합소득에서 제외 |

### 계산

**배당소득 총수입금액**
```
9,000,000 + 6,000,000 + 8,000,000 + 4,000,000 = 27,000,000
```
> **배당소득 총수입금액 = 27,000,000원** (Gross-up 가산 전)

**배당가산액**

Gross-up은 종합과세되는 배당소득 중 **기본세율이 적용되는 부분**에 한한다(제62조의 세액계산구조상). 2,000만원 채우는 순서는 ① 이자소득 → ② gross-up 비대상 배당 → ③ gross-up 대상 배당.

```
금융소득 총액 = 11,000,000(이자) + 27,000,000(배당) = 38,000,000
2,000만원 구성 = 이자 11,000,000 + 비대상 배당 9,000,000
기본세율 적용분 = 38,000,000 − 20,000,000 = 18,000,000
  → 비대상 배당 잔액 1,000,000 + 대상 배당 17,000,000

Gross-up 대상 배당 = 9,000,000(주식배당) + 8,000,000(해산 의제배당) = 17,000,000
                     (≤ 기본세율 적용분 18,000,000 → 전액 가산)
배당가산액 = 17,000,000 × 10% = 1,700,000
```
> **배당가산액 = 1,700,000원** (가산율 100분의 10 — 제17조③ 본문 단서에서 직접 확인)
>
> (참고: 배당소득금액 = 27,000,000 + 1,700,000 = 28,700,000원)

### 일반산출세액 · 비교산출세액 (제62조, 과세표준 50,000,000 가정)

제62조: 종합소득과세표준에 포함된 이자·배당소득이 종합과세기준금액(2,000만원)을 초과하면 제1호·제2호 중 **큰 금액**을 산출세액으로 한다. *(각 호의 목 단위 본문은 도구 미반환 — 통상의 계산구조에 따름)*

**일반산출세액 (제62조 제2호)**
```
2,000만원 × 14%                          = 2,800,000
(50,000,000 − 20,000,000) = 30,000,000 에 기본세율
   840,000 + (30,000,000 − 14,000,000)×15%
 = 840,000 + 2,400,000                   = 3,240,000
                                          ──────────
                                            6,040,000
```
> **일반산출세액 = 6,040,000원**

**비교산출세액 (제62조 제1호)**
```
금융소득 전액에 원천징수세율 적용
  비영업대금의 이익(㈜A로부터 직접 수령)
     6,000,000 × 25%                     = 1,500,000
  그 밖의 이자소득 24,000,000 × 14%      = 3,360,000
                                            4,860,000
(50,000,000 − 30,000,000) = 20,000,000 에 기본세율
   840,000 + (20,000,000 − 14,000,000)×15%
 = 840,000 + 900,000                     = 1,740,000
                                          ──────────
                                            6,600,000
```
> **비교산출세액 = 6,600,000원**
> (∴ 종합소득 산출세액 = MAX = **6,600,000원**)
> ※ 비영업대금의 이익 25% — 제129조①1호 *(목 단위 본문 미확인)*. 온라인투자연계금융업자를 통하지 않고 ㈜A로부터 직접 수령한 것이므로 14% 특례 대상이 아니다.

## <요구사항 3> 재해손실 · 월세 · 혼인 세액공제

### 재해손실세액공제 (제58조 · 시행령 제118조)

**요건**: 시행령 제118조①1호 — 자산총액은 **사업용 자산(토지 제외)**. 법 제58조① 후단도 "자산의 가액에는 토지의 가액을 포함하지 아니한다".
```
상실 전 자산총액 = 500,000,000 − 100,000,000(토지) = 400,000,000
자산상실비율 = 80,000,000 ÷ 400,000,000 = 20%  ≥ 20%  → 요건 충족
(장부가 소실되지 않았으므로 시행령 제118조②의 장부가액 기준 계산)

사업소득에 대한 소득세액
 = 종합소득 산출세액 × 사업소득금액 / 종합소득금액
 종합소득금액 = 30,000,000(이자) + 18,000,000(사업) + 12,000,000(근로) = 60,000,000
 = 10,000,000 × (18,000,000 / 60,000,000) = 3,000,000

공제액 = 3,000,000 × 20% = 600,000   (한도: 상실자산가액 80,000,000 이내)
```
> **재해손실세액공제액 = 600,000원**

### 월세세액공제 (조특법 제95조의2)

조문(직접 확인)상 공제율은 두 단계다.
- **15%**: 총급여 8,000만원 이하 + 종합소득금액 7,000만원 이하
- **17%**: 총급여 **5,500만원 이하 + 종합소득금액 4,500만원 이하**

```
총급여액 34,600,000 ≤ 55,000,000                    → 17% 요건 ①  충족
종합소득금액 60,000,000 > 45,000,000                → 17% 요건 ②  불충족
종합소득금액 60,000,000 ≤ 70,000,000, 총급여 ≤ 8천만원 → 15% 적용

월세액 9,000,000 ≤ 1,000만원 한도
공제액 = 9,000,000 × 15% = 1,350,000
```
> **월세세액공제액 = 1,350,000원**

### 확인하지 못한 사항 (정직한 고지)
law-mcp는 조문의 **목(가·나·다…) 단위 본문을 반환하지 않는다.** 다음은 조·항·호까지만 확인했고, 목에 규정된 수치는 확인하지 못한 채 적용했다.

1. **소득세법 제129조①1호** — 비영업대금 25% / 온라인투자연계금융업자 경유 14%. (다만 본문검색으로 소득세법 본문에 해당 문구가 존재함은 확인)
2. **소득세법 제129조①6호** — 복권당첨금 등 3억원 초과분 30%.
3. **소득세법 제62조 제1호·제2호** — 일반·비교산출세액의 계산구조.
4. **소득세법 제14조③8호** — 분리과세기타소득(복권·서화골동품)의 범위.
5. **소득세법 제12조3호** — 식사대 월 20만원 비과세 한도.
6. **소득세법 시행령 제87조2호** — 서화·골동품 의제필요경비율(90% / 9천만원+초과분 80% / 10년 이상 보유 90%). **이 항목만 답이 갈릴 수 있어** 대안 수치를 요구사항 1에 병기했다.
7. **소득세법 시행령 제208조⑤2호** — 업종별 복식부기의무자 기준금액(제조업 1.5억원).
