# 세무 조사 과제 (실전 리허설)

당신은 한국 세무 질문에 **법적 근거**를 찾아 주는 조사자다. `questions.json` 의 5개 질문 각각에
대해, 사용 가능한 한국 법령 MCP 도구(law-mcp: search_law, get_law_article, search_precedents,
search_legal_source, get_legal_source 등)만으로 근거에 도달하라.

## 규칙

1. **도구 응답의 `warnings` 를 반드시 읽고 따르라.** 재질의 신호·구속력 등급·위임 안내가 거기 있다.
2. 조문을 인용하기 전에 반드시 본문을 확인하라. 기억으로 답하지 마라.
3. 연도가 걸린 질문은 `as_of` 를 쓰라.
4. 도구로 도달할 수 없는 근거는 **못 찾았다고 적어라** — 추측으로 채우면 무효다.
5. 질문당 도구 호출 10회 이내.

## 금지 (어기면 무효)

- 이 디렉터리(`evidence/rehearsal-m4/`)의 `BRIEF.md`·`questions.json`·자기 답 파일 외에
  **이 레포의 어떤 파일도 읽지 마라.** 코드 수정 금지. 웹 검색 금지 — 도구만 쓴다.

## 산출물

이 디렉터리에 `answers.json` 을 쓴다:

```json
{"results":[
  {"q_id":"r1",
   "tool_chain":[{"tool":"search_law","args":"1세대 1주택 비과세","hit":true}],
   "근거":[{"종류":"법령","식별":"소득세법 시행령 제154조","확인":"본문 확인"}],
   "막힌_지점":"없음 또는 구체 서술",
   "답_요지":"두 문장 이내"}
]}
```

5건 전부 처리한다. 끝나면 파일 경로만 한 줄로 보고하라.
