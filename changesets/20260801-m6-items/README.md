- ADR 0001 판정: 위임 문구를 가진 24건을 포함해 **전건 본법**. 근거를 건별로 기록했다.

검증: 라벨 60/60 채움 · `verify-labels.ts` 법령명 실재 실패 0건 · 조문 실재 실패 0건.

⚠ 자기 관측(계획 finding 큐에도 기록): 추출 규칙이 본법 조문만 뽑고 산문을 그 본문에서 썼기
