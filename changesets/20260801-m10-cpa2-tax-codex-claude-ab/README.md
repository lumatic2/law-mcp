# M10 — 공인회계사 2차 세법 Codex·Claude 2×2 판정

## 목적

2026년도 제61회 공인회계사 제2차시험 세법 문제 1을 Codex와 Claude Opus가 각각 law-mcp 사용·미사용으로 풀게 하고, 사전 동결 채점표로 정확성과 도구 기여를 분리해 판정한다.

## 단계

- [x] 문제·정답·채점표 동결
- [ ] Codex·Claude 2×2 격리 하네스와 연막검증

- [ ] 블라인드 채점과 최종 판정

## Step 1 증거

- 공식 PDF/HWP와 문제 1 전사본의 크기·SHA-256을 `evidence/cpa2/2026-m10/frozen/manifest.json`에 고정했다.
- 25점 전부를 17개 점수 단위와 5개 이진 필드로 분해했다. 월세 1점은 공개 전문가 이견 때문에 분모에서 제외해 확정 분모는 24/25(96%)다.
- 공개 자료의 접근 한계를 숨기지 않고 시험일(2026-06-27) 유효 법령 본문과 결정적 계산으로 각 확정 항목을 재판정했다.
- `validate_frozen.py`가 파일·배점·필드 합계·70% 분모 게이트를 검사한다. 분쟁 배점을 인위적으로 7점 추가하면 확정 분모가 68%가 되어 실패해야 한다.
