# M9 임베딩 상한 파일럿 설계와 결과

## 질문과 비교 자

세법 12종의 제목 있는 실체 조문 **1,804개**를 모두 후보로 두고, 일상어 `query` 하나가 정답
**조문**을 top-3/top-10 안에 넣는지 잰다. 현행 비교값은 같은 dev 40건을 `searchLaw` 최종 응답으로
잰 top-3 7/40(17.5%), top-10 9/40(22.5%)이다. M8의 에이전틱 90%는 재질의·본문 확인을 포함해
단위가 다르므로 이 표의 기준선으로 쓰지 않는다.

문서 표현은 `법령명 + 조문번호 + 표제 + 본문`, 질의는 변형 없는 `query`다. 코사인 유사도와 같은
정규화 내적을 사용했다. 입력 덤프의 SHA-256은
`b39608bc018e9e0c684ae9f33a42dc6194f42e0f7f67afbce5ffe0469f9c2a1e`이고, dev 40건과 실패 세트
A 5건의 정답 조문이 인덱스에 존재함을 임베딩 전에 검사했다.

## 모델 선택과 실행 조건

| 역할 | 모델·revision | 선택 근거 | 실제 조건 |
|---|---|---|---|
| 다국어 | `BAAI/bge-m3` · `5617a9f6…` | 100개 이상 언어와 장문을 지원하는 범용 검색 모델. 모델 카드는 검색에서 질의 지시문이 불필요하다고 안내한다. [모델 카드](https://huggingface.co/BAAI/bge-m3) (접근 2026-08-01) | dense 단일 벡터, 1024차원, 최대 512토큰, CPU |
| 한국어 특화 | `jhgan/ko-sroberta-multitask` · `8fca7c9c…` | 한국어 문장·문단을 768차원 벡터로 매핑하는 SentenceTransformers 모델. [모델 카드](https://huggingface.co/jhgan/ko-sroberta-multitask) (접근 2026-08-01) | 768차원, 모델 고유 최대 128토큰, CPU |

`BAAI/bge-m3`는 원래 8,192토큰을 지원하지만, 이 파일럿에서는 두 모델의 CPU 비용을 제한하고
본문 앞부분 중심의 같은 문서 표현을 비교하기 위해 512토큰으로 제한했다. 한국어 모델은 고유 상한이
128이라 더 짧게 잘린다. 따라서 이 결과는 모델 전체 능력의 벤치마크가 아니라 **이 조건의 제품
상한 프로브**다.

## 결과 — 이득과 손실을 같이 읽는다

| 모델 | dev top-3 / top-10 | 현행 실패에서 새 top-3 / top-10 | 현행 성공 손실 top-3 / top-10 | 실패 A top-3 / top-10 |
|---|---:|---:|---:|---:|
| `bge-m3` | **21/40 · 25/40** | **17 · 19** | **3/7 · 3/9** | 3/5 · 4/5 |
| `ko-sroberta` | **20/40 · 27/40** | **18 · 21** | **5/7 · 3/9** | **5/5 · 5/5** |

임베딩은 후보 생성 능력을 분명히 높였다. 특히 한국어 모델은 실패 세트 A 5건을 top-3에서 전부
잡았고, `exp-42`(농업용 기름의 형사처벌)와 `exp-48`(관세 경정 뒤 법인세)도 1위였다. 하지만
**단독 엔진 교체**로 읽으면 두 모델 모두 AR3의 채택 문턱인 손실 0을 통과하지 못한다. `bge-m3`는
현행 top-3 성공 7건 중 3건, 한국어 모델은 5건을 top-3 밖으로 밀었다.

성능·비용도 한 방향이 아니다.

| 모델 | 벡터 인덱스 | 색인 시간 | 질의 지연 중앙값 / p95 |
|---|---:|---:|---:|
| `bge-m3` | 7,389,184 bytes | 420.849초 | 68.679 / 77.247ms |
| `ko-sroberta` | 5,541,888 bytes | 40.695초 | 21.581 / 28.577ms |

벡터 파일 자체는 작지만 이 수치에는 모델 가중치·로딩 메모리·배포 사본 동기화 비용이 포함되지
않는다. `bge-m3` 모델 카드도 정확도를 위해 hybrid retrieval과 re-ranking을 권한다. 이번 프로브는
dense 단독 상한이라, 현행 후보와 합친 뒤 재정렬하는 실제 통합 성능은 아직 **평가 못 함**이다.

## 판정에 넘길 한계

- **상한 ≠ 도달률**: top-k에 정답이 있다는 뜻일 뿐, 현행 검색과 합치고 재정렬한 최종 응답이 그
  순위를 유지한다는 뜻이 아니다.
- M8은 `pass@3` 100%다. 따라서 이득의 주효과는 최종 성공률보다 첫 시도 성공률·턴 수일 가능성이
  크며, 실제 소비 에이전트 루프 이득은 평가 못 했다.
- 인덱스는 2026-08-01 MST의 스냅샷이다. 채택한다면 후보 찾기까지만 색인을 쓰고 본문·효력은 API로
  다시 조회해야 한다. 이 전제가 깨지면 `as_of`/개정 노후 함정이 되살아난다.
- `ko-sroberta`의 A 5/5는 작은 표본이고 그중 `exp-43`은 직전 실행 아티팩트 표본이다. 5/5를 일반
  도달률로 외삽하면 안 된다.
- 단독 교체는 손실 0 문턱을 실패했다. 현행+임베딩 hybrid는 별도 재정렬 프로브 없이는 채택 근거가
  아니다.
