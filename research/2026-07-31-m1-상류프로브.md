## 1. 기본통칙·집행기준

```
lawSearch target=admrul query=기본통칙          → totalCnt 0
lawSearch target=admrul query=법인세법 기본통칙  → totalCnt 0
lawSearch target=admrul query=집행기준          → totalCnt 5  (전부 무관: 계약예규·조달청 입찰 등)
```
2026-07-21 프로브의 "법제처 경로 없음" 판정 유지. NTS(taxlaw.nts.go.kr)는 SPA 이며 상세 페이지가
무인증 200 을 주지만 본문은 초기 HTML 에 없다(§5). 문서형 자료는 내부 `action.do` 로 도달
가능하나(§5 — 이미 판례 폴백이 쓰는 API), **기본통칙·집행기준은 문서가 아니라 조문 체계**
(USESTD001M.do / USESTE002M.do)라 해당 문서 API 의 대상인지 미확인 — 검색 actionId 역공학은
D1 처분 기준(공식 API 만) 밖이라 중단했다.

## 2. 조세조약 `trty` — 완전 개통

```
lawSearch target=trty query=조세                          → totalCnt 147
lawSearch target=trty query=소득에 대한 조세의 이중과세회피 → totalCnt 106
lawSearch target=trty query=미국                          → totalCnt 24
lawService target=trty ID=8757 type=JSON                  → BothTrtyService.조약내용 (전문 텍스트)
```
검색 필드: 조약명·서명일자·발효일자·조약번호·조약구분명(양자/다자)·조약일련번호·조약상세링크.
전문 조회가 **JSON 으로 조약 전문**을 준다 — 어댑터 비용 낮음(기존 descriptor 패턴 그대로).

## 3. 빈 응답 target 어순 재확인

```
target=lsRlt  query=소득세법 → JSON lsRltSearch — 기준법령(소득세법) + 관련법령[]
                               (국세기본법=3유형(기본법)·소득세법 시행령 … 관계코드 포함)
target=rltLs             → 빈 응답
target=couseLs           → HTML 페이지 반환 (API 아님)
target=lsCouse           → 빈 응답
target=drlaw  type=JSON  → 빈 응답이지만 type=XML 은 정상 — 조문별 자치법규 위임 현황
                           (지자체별 건수 매트릭스). 세법 질의 가치 낮음
target=lawDr             → 빈 응답
```
**`lsRlt` 의 과거 "빈 응답/오답" 판정이 뒤집혔다** — 법령 간 관계(기본법·시행령·준용)가 구조화
JSON 으로 온다. CANDIDATES 의 "어순 재확인" 항목은 이것으로 소진: 어순 문제가 아니라
(추정) 과거 파라미터·시점 문제였고, 현재는 정순이 동작한다.

## 4. `expc` 는 국세청 해석례를 커버하지 않는다

```
lawSearch target=expc       query=가산세 → totalCnt 0
lawSearch target=ntsCgmExpc query=가산세 → totalCnt 1938
```
법제처 `expc` 는 법제처 자체 법령해석례 전용. 세무 유권해석은 `ntsCgmExpc`(이미 연결) 단일 경로가
맞다. NTS 세부 유형(사전답변·질의회신·과세기준자문) 구분 필드는 검색 응답에 없음 — 안건번호
접두("기준-", "서면-")로 부분 유추만 가능.

## 5. 예규 본문 도달 — 기존 폴백 API 로 가능

```
검색행: 안건번호 기준-2023-법규법인-0191[법규과-992] · 법령해석상세링크
        = https://taxlaw.nts.go.kr/qt/USEQTA002P.do?ntstDcmId=200000000000012562
GET 상세링크          → 200, 무인증, 그러나 SPA — 본문이 초기 HTML 에 없음 (안건명 미포함 확인)
lawService ntsCgmExpc ID=1643869 → HTML 에러 페이지 (법제처 전문조회 미지원 재확인)
POST taxlaw action.do actionId=ASIQTB002PR01 dcmDVO.ntstDcmId=20000...562
  → 200 JSON, ntstDcmTtl=안건명 일치, 본문 = dcmHwpEditorDVOList[].dcmFleByte (len 89,444)
```
`get_precedent` 의 NTS 폴백(`src/providers/lawgo-provider.ts:613-636`)과 **동일한 문서 API 가
예규 문서에도 동작**한다. M2 step-3(예규 본문 도달 보강)의 구현 재료.

## 6. 심판례 미러 신선도 — 우려 기각

```
lawSearch target=ttSpecialDecc query=가산세 sort=ddes → totalCnt 4694 (07-21: 4688)
최신 5건: 의결 2026.07.15 / 07.13 / 07.07 / 06.30 / 06.30 · 데이터기준일시 2026.07.20~29
```
07-21 프로브가 본 "데이터기준일시 2024.12.18" 은 해당 문서의 속성이었을 뿐, 미러는 최근 의결까지
수록하며 lag 는 약 1~2주. 라이브 질의 아키텍처로 충분 — 별도 동기화 불요 판정.

## 7. 국세청 고시

```
lawSearch target=admrul query=기준시가 → 10건, 전부 종류=고시, 국세청 소관 다수
  (건물 기준시가 계산방법·골프회원권·공동주택·상업용 건물 …)
```
기준시가류 고시는 기존 `search_admin_rules`(=`admrul`)로 도달한다. 신규 연결 불요.

## 남는 미확인 (판정 불능이 아니라 범위 밖)
