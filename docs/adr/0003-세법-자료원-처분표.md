# ADR 0003 — 세법 자료원 처분표 (근거 유형 14행 전수 판정)

- 상태: 확정 (2026-07-31, M1 step-1)
- 근거: `research/2026-07-31-세법완성-자료원지도.md`(유형 지도) ·
  `research/2026-07-31-m1-상류프로브.md`(실측)
- 처분 기준(사용자 승인 2026-07-31, M1 plan 결정 로그 D1): **공식 API 가 있는 것만 연결한다.**
  스크래핑·비공식 endpoint 역공학은 하지 않는다. 공백은 "공백+이유"로 기록하고 실무 영향은
  M4 리허설이 잰다. (예외 선례: NTS `action.do` 문서 API 는 이미 판례 폴백이 사용 중인 표면이라
  같은 API 의 재사용은 신규 표면 개척으로 보지 않는다.)

## 부수 판정 (근거 유형 밖 target)

- **`lsRlt` 법령 관계 — 연결 후보로 재개봉**: 과거 "빈 응답/오답" 판정이 뒤집혔다(실측 정상 JSON,
  기본법·시행령 관계 구조화). 단 세법 완성 필수축이 아니라 M2 범위에 넣지 않고 CANDIDATES 적재.
  `lsStmd`(체계도)와 역할 중복 — 채택 시 하나만.
- **`dlytrm`**: 검색 정상(578건) 재확인. 어휘 공백 브리지 후보 — CANDIDATES 유지.
- **`drlaw`**: XML 전용, 조문별 자치법규 위임 현황 — 세법 가치 낮음, 미연결.
- **`couseLs`·`lawDr`·`rltLs`**: API 아님/부재 확정 — 어순 재확인 항목 소진.

## 이 처분이 뒤집히는 조건

- 8·9번: 법제처가 통칙·집행기준 target 을 열거나, NTS 가 공식 API 를 공개하면 재판정.
- 14번: 국세청 심사청구가 특별행정심판 계열 target 으로 확인되면 M2 패턴으로 저비용 연결.
- M4 리허설이 8·9번 공백 탓의 도달 실패를 드러내면 → decision_required (M4 plan 중단점).
